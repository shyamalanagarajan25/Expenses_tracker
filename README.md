SpendWise: Personal Expense Tracker
A beginner-friendly desktop application built with Python and Tkinter to record daily expenses and track the total spend automatically.
Features

•	Add an expense with an item name and amount

•	Total amount updates automatically after every entry

•	Delete a selected expense (the total reduces automatically)

•	Clear All button to reset the list and total

•	Input validation with error pop-ups for empty or non-numeric values

Tech Stack

•	Python 3

•	Tkinter (built-in GUI library, no installation needed)

How to Run
1.	Install Python 3 from python.org
2.	Download Expense_tracker.py
3.	Open a terminal in the file's folder and run: Expense_tracker.py
   
How It Works
1.	The user types an item and an amount
2.	The app checks that both fields are filled and the amount is a number
3.	The expense is added to the list and the total is updated
4.	Selecting a row and clicking Delete Selected removes it and subtracts its amount

What I Learned

•	Arranging widgets in rows and columns using the grid layout

•	Handling button click events with functions

•	Validating user input with try/except and message boxes

Future Improvements
